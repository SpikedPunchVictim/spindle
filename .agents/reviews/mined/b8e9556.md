## Reading

This is the richest single record in the range: an adversarial review of 2074100 (the commit that added a `devices.alg_id` column and a fail-closed check against it) found four real defects, all of which had survived a fully green gate of 753 tests and four neuters the implementer had personally reported as proof. Three are genuine security-relevant bugs in the shipped code (a silently-truncating integer cast that let a corrupted alg_id of 257 alias to valid v1; a Rust `let Some(CONST) = ... else` construct that bound nothing and left the primary authorization site still hardcoding the value the ticket was meant to eliminate there; an asymmetric guard between two write paths for the same column). The fourth and most methodologically important is a self-defeating test: the review found that the test meant to prove the new check failed closed on an unsupported algorithm had built an internally inconsistent database row, so a completely different, later check was doing the denying and the intended check was never exercised at all — deleting it left the whole suite green. The implementer goes further and corrects their own prior claim that a neuter had proven this same check load-bearing, since that neuter (relaxing a constant pattern to `Some(_any)`) had left a different guard (the None case, enforced at compile time by an irrefutable-pattern hazard) doing the work being credited to the check under test.
