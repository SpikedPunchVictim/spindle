## Reading

Two real defects were found in 4fc2a04 — the commit implementing the device bootstrap bundle — by an adversarial review conducted after that commit had already passed its own full green gate. The first is a build/decode asymmetry: the encoder never enforced a length cap the decoder enforced, so the builder could construct a bundle that would then be rejected by its own decoder, and the resulting error path additionally lied about a recovery path that its own doc comment promised (`TooLargeForQr` claiming `entries[..fits]` would succeed when `fits` was left at its uninitialized default of 0 and nothing actually fit). The second is a cross-language semantic disagreement: the Rust implementation of bundle verification always copies/owns its output, while the TypeScript port returned live aliases into the caller's unverified input, meaning a later mutation of the original bundle silently mutated the "verified" result with no signal. Both are exactly the "shipped, passed a green gate, and was still wrong" pattern this filing task targets, and both are confirmed with an executable neuter in each language rather than reasoned about.
