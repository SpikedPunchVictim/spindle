## Reading

The primary finding is another instance of the same class the td-331c11 lineage kept exposing: a constant asserting something about the world (the NATS server's actual configured control-line limit) with nothing validating it against the thing that actually decides it. An independent reviewer's demonstration is stark — silently lowering the deployed config's limit left the entire test suite green while every real 32-cap CONNECT token would be dropped in production, meaning the test that was supposed to guard the token-size ceiling was actively misleading about server behavior it never checked. Two smaller, self-noticed findings round out the commit: a TypeScript documentation constant that had drifted from its Rust counterpart for an unspecified period while nothing consumed its value in either language (found by a full-repo sweep of 24 shared-name constants, of which this was the only one that had drifted), and a small misquote of a DESIGN.md percentage figure caught by the td-534c54 review lineage.
