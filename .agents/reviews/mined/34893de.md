## What the commit says

> The regression test guarding the byte-vs-character bug in `remove_uploads_under`
> stopped catching it, and nothing noticed because it kept passing.
>
> `fe9ccd0` fixed a real defect: Rust's `str::len()` counts BYTES while SQLite's
> `substr`/`length` count CHARACTERS on TEXT, so a Rust-computed prefix length
> silently stranded every descendant of a non-ASCII subpath. The test written for
> it used "dossié". Then `7c4d124` moved the comparison onto `fold_subpath` — and
> `fold_key` maps the Latin-1 accented letters to their base, so "dossié/" folds
> to the pure-ASCII "dossie/": 7 characters AND 7 bytes. The two counts agree on
> that input, so the test could no longer tell the fix from its absence.
>
> This is a failure mode worth naming: the test was correct when written and was
> invalidated by a LATER commit changing the data it runs on. Not bad input
> selection — downstream drift.
>
> Also corrects five doc comments that had gone stale or were false: [schema.rs
> ownership-ledger claim, mod.rs adjust_share_upload_bytes claim, server.rs
> misattributed comment citations, schema.rs V7 migration test claim, upload.rs
> NFC/NFD test caveat]
>
> Found by an independent review of td-b940b1.

## Reading

This is the cleanest example in the range of a regression test silently losing its ability to fail: a downstream refactor (7c4d124) changed the data a fixture string folds to, collapsing the byte/character distinction the test depended on, and nothing in the gate could tell the difference — the suite stayed green through the entire window. The independent review that caught it also swept the surrounding doc comments and found four more claims that had gone stale (two by a later commit superseding them, one by a citation slipping to the wrong file/function, one by a test-intent comment describing a stronger check than the query actually performs) plus one comment claiming a filesystem-level proof that macOS structurally cannot provide. The common thread across all six findings is that the commit history's own natural drift — an unrelated fix elsewhere, a citation aging past an edit — silently invalidated a documented claim, and only a dedicated audit pass surfaced it.
