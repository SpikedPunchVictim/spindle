## Reading

Independent adversarial review of the prior nesting-depth fix (0280788)
found two substantive issues (a third, a cosmetic Display-string
inconsistency, is not filed here as it carries no functional claim). First,
the doc comment's own measured "8x headroom" figure was wrong because it
counted structural depth using a different convention (counting the leaf as
a level) than the one the guard constant is actually compared against,
understating the true headroom (10.7x) while overstating a smaller number —
a mismeasured figure that had already shipped in a doc comment. Second, and
more consequential, the new `MAX_NESTING_DEPTH` constant was re-exported from
the Rust crate root but not from the TypeScript package's public barrel, and
the existing test suite could not have caught this because it imports around
the barrel entirely — a parity gap between the two language implementations
of the same protocol, verified fixed by importing the built barrel at
runtime rather than by reading the source.
